# Feliz día, seño Agus

Regalo web interactivo por el Día del Maestro para Agustina.

## Experiencia

- Campo procedural de girasoles animado con GSAP.
- Parallax suave con puntero y scroll.
- Carta/discurso personal de Damián.
- Interacciones para hacer florecer el campo, sembrar girasoles y lanzar pétalos.
- Responsive y con fallback para `prefers-reduced-motion`.
- Sin build step: el sitio vive completo en `index.html`.

## Desarrollo local

Podés abrir `index.html` directamente o servir la carpeta con cualquier servidor estático.

## Deploy

GitHub Actions publica automáticamente `main` en GitHub Pages mediante `.github/workflows/pages.yml`.
